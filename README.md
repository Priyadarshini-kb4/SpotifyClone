# SpotifyClone

📌 **What the Project Is**  
This is a personal web page built as a frontend project using HTML and CSS. It includes a clean, responsive layout with modern design elements. The page showcases structured sections like a header, hero image, content cards, and footer — ideal for a personal portfolio, landing page, or practice layout.

🔧 **How It Was Built**  
- **HTML5**: For the page structure (semantic elements like `header`, `section`, `article`, `footer`)
- **CSS3**: For styling and layout using Flexbox, custom colors (`var(--green)` for theme consistency), and media queries
- Designed to be visually appealing and easy to navigate
- Uses best practices like reusable variables, organized class names, and responsiveness
